# Android Calculator App

This is a simple calculator application built in Android Studio using Java.

The purpose of this project was not only to understand basic Android development concepts, but also to get familiar with GitHub and version control.

## Features
- Addition, subtraction, multiplication and division
- Input validation with simple error handling
- Clear button to reset results
- Basic user interface

## Technologies Used
- Java
- Android Studio
- XML (UI design)
- Gradle (build system)
- Git & GitHub (version control)

## What I Learned
- Handling button click events (OnClickListener)
- Working with EditText and TextView
- Basic input validation and error handling
- Understanding Android project structure (Java, XML, Gradle)
- Uploading and managing a project using GitHub
